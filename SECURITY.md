# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability, please report it responsibly.

**Do NOT open a public issue.** Instead, please email: contact@coderooz.in

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- Initial acknowledgment: Within 48 hours
- Status update: Within 1 week
- Resolution: Depends on severity

## Security Considerations

This is a development/learning project. For production use, consider:

- Adding persistent storage with proper data validation
- Implementing rate limiting
- Adding user authentication
- Using environment variables for secrets
- Enabling HTTPS
- Adding input validation and sanitization

## Best Practices

When using or extending this project:

1. Never commit secrets or API keys
2. Use environment variables for configuration
3. Validate all user inputs
4. Implement proper error handling
5. Keep dependencies updated
